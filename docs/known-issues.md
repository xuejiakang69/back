# 已知问题与优化建议

## 已知问题

| 序号 | 问题 | 风险等级 | 说明 |
|------|------|----------|------|
| 1 | 数据库密码明文写在配置文件中 | 🔴 高 | 安全风险，应使用环境变量 |
| 2 | schema.sql 每次启动执行 | 🟡 中 | 生产环境应改为 `never` |
| 3 | 实体类缺少时间字段映射 | 🟡 中 | `created_at` 和 `updated_at` 未在 User.java 中定义 |
| 4 | 无输入校验 | 🟡 中 | Controller 层没有 `@Valid` |
| 5 | 无异常处理 | 🟡 中 | 没有全局 `@ControllerAdvice` |
| 6 | 无分页 | 🟢 低 | `selectAll` 查询所有用户 |

---

## 优化建议

### 高优先级

1. **添加 `@Valid` 参数校验**
   - 在 Controller 方法参数上添加 `@Valid` 注解
   - 在实体类上添加校验注解（`@NotBlank`, `@Email` 等）

2. **添加全局异常处理**
   - 创建 `@ControllerAdvice` 类
   - 统一处理业务异常和参数校验异常

3. **使用环境变量存储敏感信息**
   - 数据库密码等敏感信息使用环境变量
   - 配置文件中使用 `${ENV_VAR}` 占位符

### 中优先级

4. **实现分页查询**
   - 使用 MyBatis 分页插件
   - 或手动实现 LIMIT 查询

5. **添加事务管理**
   - 在 Service 层添加 `@Transactional` 注解
   - 确保数据一致性

### 低优先级

6. **删除无用的 `Main.java`**
   - 该文件为 IDE 模板，可安全删除

7. **实体类映射时间字段**
   - 在 User.java 中添加 `createdAt` 和 `updatedAt` 字段
   - 使用 `@TableField` 注解映射数据库字段
